## 3. 設計

**1 つの case に 2 つの mode を持たせ、同じ run で対にする。**

- **`direct`**: **plugin を読み込まない**（`run.sh:751`。プラグイン無しで起動する）。
  親が 3 ファイルを自分で読む。**フックが無いので deny も委譲も起きない。**
- **`auto`**: plugin 有り。**A と同じ prompt、同じ 3 ファイル、同じ gold。**

**対になるので、モデルの日ごとの調子も corpus も共通である。**

## 4. 主要指標

**1 対あたりの実費の差 `auto − direct`（USD）。**

**対応のある符号反転置換検定（両側、10,000 反復、`Random(20260918)`）。**
**Wilcoxon ではなく符号反転置換にするのは、差が連続量で
分布の形を仮定したくないためである。**

**予測は立てない。符号すら分からない。**
`auto` は worker の入力に corpus 全文を渡すぶん高く、
`direct` は親の文脈に全文が積もるぶん高い。**どちらが勝つか分からない。**
**「分からないほうを測る」というのが §2 の理由である。**

### 4.1 N = 40 対と、その検出力

差の標準偏差を **$0.0681**（A の `auto` の SD $0.0481 の √2 倍。
**2 腕が独立という最悪の仮定**。対なら実際はこれより小さい）として、
符号反転置換検定（両側 α=0.05、`Random(20260918)`）:

| 差 | n=25 | **n=40** | n=55 |
|---|---|---|---|
| $0.02 | 0.27 | **0.44** | 0.56 |
| $0.03 | 0.59 | **0.78** | 0.89 |
| $0.05 | 0.93 | **0.99** | 1.00 |
| $0.08 | 1.00 | **1.00** | 1.00 |

**n=40 で $0.03 の差なら 0.78、$0.05 なら 0.99。**
**前の設計と違い、都合のよい 1 行だけではない。**
**これは指標を率から連続量に変えたことの直接の効果である。**

**$0.02 未満の差は検出できない**（0.44）。**それは先に認めておく。**

## 6. 予測を外したときにどう書くか（事前に決める）

**予測を立てていないので、「外す」という書き方をしない。**
代わりに**符号ごとに文言を先に決める:**

- **`auto` が有意に高い**（p<0.05, 差>0）なら、
  「**この case では、委譲は親の文脈を空にする代わりに
  1 対あたり $X 高くついた。**」
- **`auto` が有意に低い**なら、
  「**この case では、委譲は親の文脈を空にした上で $X 安かった。**」
  **「だから常に安い」とは書かない。** case は 1 つである。
- **p ≥ 0.05** なら、「**差を検出できなかった。**」と書き、
  **§4.1 の表を併記する。「差が無い」とは書かない。**
- **いずれの場合も、金額の差と一緒に §5 の 1（バイト）と 3（時間）を
  必ず並べる。** **値段だけ、あるいは効能だけを単独で書かない。**

**ここに書いた文言は今決めている。後から動かさない。**

## 8. 事前に認めている弱点

- **`direct` 腕は plugin を読み込まない。** したがって比べているのは
  「委譲した auto」対「plugin 非導入」であって、
  **「plugin を入れたが委譲しなかった場合」ではない。**
  **導入の是非には答えるが、委譲判断の是非には答えない。**
- **`accuracy` は天井に近い**（A で 23/23）。
  **差が出ないことをもって「同等」と言わない。**
  さらに `gold` の 3 語は公開された Django の名前なので、
  **読まずに当てられる。** §5 の 5 はそのための計数である。
- **case は 1 つ、corpus は 1 つ、言語は 1 つ、ファイルは 3 件。**
  **ファイルの選択は私が行った。**
- **価格は今日のモデル価格に依る。** 差の絶対額は再現しない。
- **$0.02 未満の差は検出できない**（§4.1）。
- **`ScheduleWakeup` と `Skill` は `--allowedTools` に無いのに使われる**
  （A の preflight 5）。**`direct` 腕でも同じ条件である**が、
  **待ちの有無が `wall_ms` に効く可能性がある。**
- **漏れ率の問いは未解決のまま残る。** 本ブロックはそれを解かない。
