## 1. 主要（事前登録どおり）

48 対の（`direct` の実測 `parent_read_bytes`）×（auto の費用 − direct の費用）:

**Spearman ρ = −0.879、並べ替え検定（両側・10,000 回・`Random(20260917)`）p = 0.0001。**

**予測どおり負である。§1 の 2 点は偶然では説明できない。**

**p = 0.0001 は 10,000 回の分解能の下限（1/10001）であって点推定ではない。**
「0.0001 より小さい」としか言っていない。

## 2. 何が効いているのか（同じデータの内訳、探索的）

| 相関（block2 48 対） | ρ | p |
|---|---|---|
| direct の費用 × 読まされた量 | **+0.921** | 0.0001 |
| auto の費用 × 読まされた量 | +0.151 | 0.30 |

**負の相関は「auto が安くなる」ではなく「direct が高くなる」から出ている。**
auto の費用は読まされる量にほとんど反応しない。
これは仮説の意味するところと一致するが、**方向を取り違えないよう明記しておく。**

### 3.1 用量をファイルサイズで代用しなくて正解だった

## 4. 本文は親に入ったか（副次 2）

`auto` の `parent_read_bytes` が **0 でない run が 48 中 2 件**あった。
中身を確認したところ **両方ともフックの拒否文（1,181 B）**であり、**本文ではない。**

```
File exceeds token-shunt thresholds (lines=351/350, bytes_scanned=11105/65536). ...
```

`parent_read_bytes` は Read の結果を数えるので、**拒否文も数える。**
**本文としては 48/48 で 0 バイト。** block1 の 40 run（再集計して確認）と合わせ **88/88 で 0。**

## 5. 見つかった実機の不具合（product 側）

**`redmine-last-query` の auto 腕 12 run 中 3 run が `child_no_body` で fail した。**
worker が返信にコードフェンスで `def` 行を 1 行貼っている:

```
def joins_for_order_statement(order_options)
```

- **これは本文を返さないという契約の違反である。** 量は 1 行だが、規則は量で測っていない。
- 全体では **48 中 3（6.3%）**、この case 内では **12 中 3（25%）**。他の 3 case では 0。
- **答は 3 run とも正しい**（`accuracy_any` は通っている）。落ちたのは無本文の規則だけ。
- **ここでは直していない。** 事前登録した測定の途中で製品を変えない。

## 9. 解析側のミス（気づいて直した。課金なし）

block1 の run ディレクトリを `/tmp/ts-rm-block1-runs` に移してあったため、
`parent_read_bytes` の `--root` 前置詞照合が transcript 内の**旧絶対パス**と一致せず、
**block1 の direct を全件 0 バイトと出していた。**
root を元の位置で解決して再集計し、前回記録の中央値（10,278 / 46,086 B）と一致することを
確認した上で §6 を出している。**0 という値がもっともらしく見えたのが危なかった**
（§4 の結論と同じ形の数字だったため）。

## 10. 結論

- **「親が読まされる量が多いほど auto の費用上の不利は小さくなる」は支持された**
  （48 対、ρ = −0.879、p < 1e-4）。
- **効いているのは direct 側の費用増**であって、auto が安くなるわけではない。
- **費用の損得が入れ替わるのは、実測で 2〜3 万バイト飲まされるあたり**（4 点による）。
- **本文が親に入らないという前回の結論は、この 48 対でも成り立つ**（88/88 で 0 バイト）。
- **無本文の規則には実機で 6.3% の違反がある**（§5）。これは別途扱う。

## 11. 事前に認めた弱点（再掲、変更なし）

問いの形は「末尾の定義を訊く」1 種類のみ。費用は今日のモデル価格に依存する。
用量と費用差は同じ run から来るので独立ではない。
**この設定でそう動く、以上のことは言っていない。**
