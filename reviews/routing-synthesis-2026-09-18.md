## 1. 委譲は当たる — 143 run で漏れは 1 件

**plugin を入れた腕は合計 143 run**（計画フェーズ 80 + A 23 + B の auto 40）。
**親が委譲せず自分で本文を読んだのは 1 回だけである。**

| 条件 | 漏れ |
|---|---|
| 3 件とも deny を引く（442/707/508 行） | **0 / 80** |
| 3 件とも deny を引かない（177/111/333 行） | **1 / 63** |

**deny の有無にかかわらず、親はほぼ委譲する。**
**これは製品にとって良い結果である。**

**ただし副作用がある: 測定として行き止まりになる。**
率が 0.016 では、どんな腕を足しても差を検出できない。
**計画文書の形が routing を改善するか**という当初の問いは、
**改善する余地が無いという形で終わった**（`plan-phase-routing` §5）。

## 2. 文脈は実際に守られている — 重なりが無い

B の 40 対（`subthreshold-cost` §2.1）:

| | 親の文脈に入ったバイト（中央値） | corpus 合計 23,729 B 未満 |
|---|---|---|
| plugin 非導入（`direct`） | 29,813 | **0 / 40** |
| plugin あり（`auto`） | **12,380** | **40 / 40** |

**両腕の分布に重なりが無い。** 「文脈を守る」という主張は、
**この case では成り立っている。**

## 3. 値段が初めて分かった

**1 run あたり $0.062 高い**（`auto` $0.1597 対 `direct` $0.0983、
40/40 で auto が高い、p = 0.00010）。**約 1.63 倍。**

**時間の代償は無かった**（中央値で `auto` が 7.8 秒速い）。
**ただし遅い尾は `auto` のほうが悪い**（最大 83.4 s 対 34.2 s）。

**正答は両腕 40/40 で差が見えない。**
**これは「同等」の証拠ではない。天井である。**

## 4. 最初の問いに、どこまで答えられたか

### 「運用レベルまでいく見込みはあるか」

**routing の信頼性については、答えは肯定的である。**
143 run で 1 件。**そこは心配の種ではない。**

**代わりに分かったのは値段である。** 1 run $0.062、約 1.63 倍。
**運用の判断は「動くか」ではなく「この倍率を払うか」に移った。**
**それは測定ではなく、使う人が決めることである。**

**未測定のまま残っているもの:**

- **編集を含まない。** v0.1 は deny 対象ファイルの編集を範囲外と
  明記している（`plugin/hooks/check-file-size:151`）。
  **実装フェーズの適合性は 3 ブロックのどれも測っていない。**
- **`direct` 腕は plugin 非導入である。**
  **「plugin を入れたが委譲しなかった場合」は一度も測っていない。**
  導入の是非には答えたが、**委譲判断の是非には答えていない。**

### 「SDD のような使い方に役立つか」

**答えていない。** 3 ブロックはすべて
**1 問 1 答の単発 run** である。**SDD は多ターンの営みであり、
文脈保護の値打ちは「セッションが長いほど効く」という形で主張される。**

**測ったのは、1 回の読み取りで 17,433 B 節約できたということだけである。**
**それが 50 ターンの設計セッションで何を意味するかは、
本日のどの数字からも出てこない。**

**役に立つ見込みがある、と言える根拠はある**（§1 と §2）。
**役に立つと測った、とは言えない。**

## 5. 残っている問いと、残高

**上限 $200 に対し累計 約 $162.3。残り 約 $37.7。**

**測る価値があり、かつ残高で届くもの**（提案であって決定ではない）:

1. **多ターン。** 同じ corpus を複数回参照する会話で、
   plugin 有無の親文脈がどう開くか。**§4 の「答えていない」に
   直接あたる唯一の設計である。**
2. **plugin 導入下の非委譲 baseline。** `direct` を
   「plugin あり・委譲を促さない」に置き換える。
   **§4 の 2 番目の穴を塞ぐ。**
3. **編集。** 範囲外と明記されている以上、
   **測るなら先に製品側の判断が要る。**

**1 が最も大きい穴である。** 本日の 3 ブロックは
**「1 回の読み取り」については十分に答えており、
残る不確かさはそこではない。**
