# 委譲不発の原因を探した（239 会話、$0、仮説は否定された）

`reviews/subthreshold-unprotected-2026-09-20.md` が「親が委譲を飛ばすと
拒否経路が 1 本も残らない」と示した。**ではなぜ飛ばすのか。**
アーカイブ 239 会話と今日の 9 会話に当てた。**課金していない。**

計器は `judge.Transcript.agent_uses` / `agent_type_of` / `all_tool_uses` と
`parent_bytes.parent_read_bytes`。**採点器を書いていない。**

## 1. 起動の有無と汚染は完全に一致する

| | reader 起動あり | reader 起動なし |
|---|---|---|
| 本文が親に入った（`unprotected`） | **0** | **2** |
| 入っていない（`no_attempt` / `denied`） | **237** | 0 |

今日の 9 会話でも同じ形が出た: `reader=0` の 1 本（`G1Xd4PM1`）だけが
25,901 B で、残り 8 本は 0 B か拒否文だけである。

> **248 会話で例外が 1 件も無い。** worker を起動した会話で本文が入ったことは無く、
> 起動しなかった会話で本文が入らなかったことも無い。

**これは因果の証明ではない。** 完全分離は
「起動が守る」と「飛ばす親はもともと読む親である」を**区別できない。**
アーカイブは介入ではないので、ここから先は分けられない。

## 2. 見えていた唯一の候補は、否定された

不発 2 本（`B8fdHRZY`、今日の `G1Xd4PM1`）は**行動列が一致していた**:

```
1手目  Bash: wc -c（または -l）で 3 ファイルをまとめて測る
2手目  Read: showmigrations.py
3手目  Read: recorder.py
4手目  Read: graph.py
```

**「サイズを測って、小さいと分かったから自分で読んだ」**という筋が立つ。
`check-bash-read` は `wc` を通す（本文を返さないので当然である）。

**この仮説は成立しない。** 239 会話を数えた:

| | `wc` を 1 手目に打った | 打っていない |
|---|---|---|
| reader 起動あり | **190** | 47 |
| reader 起動なし | 1 | 1 |

**1 手目の `wc` は 191/239（80%）で、委譲した会話の標準的な出だしである。**
それを打った 191 本のうち、委譲を飛ばしたのは **1 本**である。
**候補の基準率が 80% で、結果が 1/191 なら、それは原因ではない。**

（`read-the-arm-before-specifying-it` と同じ形である。違うのは、
今回は**仮説を書く前に $0 で数えたので、何も買わずに済んだ**ことである。）

## 3. 原因は特定できていない

- **`auto-edit-grep-location` の不発は別物である。** `wc` も打たず、
  入ったのは 83 B である。§1 の表には入るが、§2 の筋とは関係しない。
- **transcript に残っている行動だけでは、残り 1 本の分岐点が見えない。**
  不発 2 本と委譲した 190 本は、**1 手目まで同一**である。
  分かれるのは 2 手目（Agent か Read か）で、
  **その間に親が何を考えたかは transcript に無い。**

## 4. 実機で率を測れるか（$0 の算数、走らせていない）

観測率は `django-subthreshold-bare` で **2/110**（アーカイブ 1/101 + 今日 1/9）
= 1.82%。1 run $0.2476（今日の実測）で:

| n | 期待発生 | **1 件も出ない確率** | 費用 |
|---|---|---|---|
| **23**（残予算 $5.8 の上限） | 0.42 件 | **65.6%** | $5.69 |
| 50 | 0.91 件 | 40.0% | $12.38 |
| 126 | 2.3 件 | 9.7% | $31 |

> **残予算 $5.8 を全部使っても、3 分の 2 の確率で発生 0 件に終わる。**
> **発生 0 件は「委譲不発が起きない」ではない**（率 1.8% なら普通に起こる）。
> **買っても率は言えない。**

**走らせないことを勧める。** Lock B のときと同じ形である ——
`cumulative-intake-run-sheet-2026-09-19` が率 1/15 に対し
n≈55〜70/腕が要ると出して見送った。**今回は率がさらに一桁低い。**

**測るなら、率ではなく機構を変えてからである。** §1 の完全分離は
介入で切れる: **委譲を飛ばした親に拒否を掛ける経路**を作れば、
`unprotected` が `denied` に変わるかどうかは**1 件でも観測できる。**
率を買うより安い。**ただしそれは設計であって、本書はそこへ進まない。**

   §2 は 239（アーカイブのみ）、§4 の 2/110 は
   `django-subthreshold-bare` だけである。**同じ分母ではない。**
