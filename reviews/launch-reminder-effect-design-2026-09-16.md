# `check-worker-launch` 効果確認の事前登録（2026-09-16）

`reviews/a-suite-failures-9346d19-2026-09-16.md` §10 で入れた予防フックが、
実機で (a) 届くのか、(b) 親のパス短縮を減らすのかを測る。
**本記録は走らせる前にコミットする。** 項目・N・判定基準は事前に固定し、
結果が出てから基準を動かさない。

## 1. 測る主張

§10.1 は CLI バイナリの文字列から「PostToolUse の `additionalContext` は
モデルに配送される／PreToolUse は配送されない」と読んだ。**これは観測ではない。**
配送されなければ §10 の実装は無意味であり、短縮が減るかどうか以前の問題になる。
よって配送の確認を先に置き、通らなければ止める。

短縮そのものは親（常に `--model sonnet`。モード名はワーカー側の指定）の
挙動であり、指示文の追加が効くかどうかは実機でしか分からない。

## 3. 枠と N

枠は 3。いずれもワーカーが絶対パス付き `confirmed:` を返す委譲枠で、
うち 2 つは**フック deny を経ない明示委譲**（§10.2 が狙った経路）。

- `compare-explicit-multifile/haiku`（§1 で短縮が観測された枠）
- `compare-explicit-multifile/auto`
- `auto-explicit-multifile/haiku`

**1 腕あたり 2 周 × 3 枠 = 6 run、合計 12 run、`run.sh` 起動は 4 回。**
`SENDBACK` は既定の off。入だと Stop フックが短縮を事後修復してしまい、
予防の効果が測れない。

**順序は treatment を先に走らせる。** E2 が 0 なら control 腕は不要になり、
その分を使わずに済む。

## 4. 事前登録する項目

計器は `evals/compare/retention_probe.py`（本コミットに同梱、テスト 8 件）。
判定は製品自身の `sendback_retention.check_line_retention` を使う。

| # | 項目 | 定義 |
|---|---|---|
| E1 | 短縮 | run 単位。ワーカーの `confirmed:` 行（絶対パスが実在するもの）が最終回答に逐語で残らなかった run 数 / 測定可能だった run 数 |
| E2a | フック応答 | 予防フックが payload を返した run 数 |
| E2b | **配送** | その文言がフック応答**以外**のイベントに現れた run 数 |
| E3 | 合否 | 枠ごとの verdict |
| E4 | 費用 | run ごとの `total_cost_usd` |

`gold_confirmed` は使わない。gold に乗ったパスが落ちたときしか反応せず、
E1 より粗い。ワーカー行が 1 本も無い run は `undetermined` として
**分母から外す**（`ok` に数えると treatment を不当に良く見せる）。

## 5. 判定基準（事前）

1. **E2b が treatment で 0 なら、そこで止める。** 「PostToolUse の
   additionalContext は配送される」という §10.1 の読みが誤りだったと記録し、
   control 腕は走らせない。実装は撤回するか、配送される別イベントに
   載せ替える議論に戻す。
2. E2b が 6/6 で、**control の短縮が 4/6 以上かつ treatment が 1/6 以下なら、
   予防は支持される。** Fisher 両側 p を併記する（6/6 対 0/6 で p ≈ 0.002、
   4/6 対 0/6 で p ≈ 0.061）。
3. **control の短縮が 3/6 以下なら、この N では基準率が低すぎて測れない。**
   「効果なし」とは書かない。観測された基準率だけを記録する。
4. treatment の短縮が control 以上なら、支持されない。
5. **延長は 1 回だけ**: 方向が一致していて p > 0.05 のときに限り、
   1 腕あたり 1 周（3 run）追加してよい。それ以外の延長はしない。

## 6. 費用

$0.16 から、12 run + 4 起動で **約 $2.7**。延長した場合 +$1.4。**上限 $5。**
超えたら止めて、そこまでの結果で記録する。
